# Disk Toggle · 硬盘开关

> 把任意硬盘在「联机」和「脱机」之间一键切换的 Windows 小工具。
> **不点就不动**——没有后台常驻进程，不装驱动，不碰系统服务。

---

## 它解决什么问题

机械硬盘只要还挂在系统里，索引服务、杀毒、缩略图、各种客户端就会时不时去读它一下，
盘就一直转着、响着。Windows 自带的功能里没有"把这块盘临时摘掉"的按钮。

这个工具就是那个按钮：

- **脱机**后，Windows 里根本没有这块盘——不分盘符、不进资源管理器、任何程序都碰不到，硬盘自然停转
- **联机**后，几秒内盘符回来，和插上一样
- 全程只做一件事：`Set-Disk -IsOffline`，不移动、不修改任何数据

---

## 特点

- **一键总开关 + 每块盘一个开关**：图标随状态自动变化，看一眼就知道现在是开还是关
- **重新插拔也认得**：按**磁盘序列号**识别，盘符变了（比如 F: 变成 G:）也能对上
- **用前有检查**：卸载前会关掉指向该盘的文件资源管理器窗口、检查有没有程序在跑、采样写入活动
- **移动硬盘会真停转**：顺带打开 USB 省电挂起，硬盘盒才会断电停转
- **全程有日志**：每次操作的结果和每一步过程都记下来，出问题能查
- **零依赖**：只需要 Windows 自带的 .NET Framework / PowerShell，不装任何运行时

## 快速开始

### 1. 拿到文件

```powershell
git clone https://github.com/wzhhhhhhhhhhhh/drive-toggle.git
```

或者直接下载压缩包解压到任意目录（路径里有中文、空格都没关系）。

### 2. 双击 `初始化.exe`

会弹一次 UAC（这是**唯一**一次需要管理员权限的地方），然后在窗口里勾选要管理的磁盘：

```
☑ D:   <你的磁盘型号>      931 GB   SATA
☐ E:   <另一块盘>          1863 GB  USB · 移动硬盘
```

系统盘不会出现在列表里。至少选一块，点「确定」。

### 3. 之后就用桌面图标

初始化完成后，桌面上会出现：

| 图标 | 作用 |
|---|---|
| **硬盘开关** | 总开关：一块在线就全部断开，全部脱机就全部接入 |
| **硬盘开关 - D 盘** | 只动这一块盘，其它盘不受影响 |

双击即可，**不会弹 UAC、不会闪黑窗**。

## 日常使用

- **总开关**：只要有一块盘在线，点下去就是"全部断开"；全都在脱机时，点下去是"全部接入"
- **单盘开关**：只影响那一块盘，其它盘保持原样
- **耗时**：挂载约 5–15 秒（盘要转起来 + 系统分配盘符），卸载约 5–15 秒（含 2 秒写入采样）
- **盘符变了**：图标上的角标会自动跟着变，不用管

### 图标怎么看

| 外观 | 含义 |
|---|---|
| 绿色硬盘 | 这块盘现在**在线**（联机） |
| 灰色硬盘 | 这块盘现在**脱机** |
| 右上角字母 | 当前盘符，盘符变了图标跟着变 |
| 右下角插头 | 点一下的结果：插上＝会接入，断开＝会断开 |

## 工作原理（简述）

1. 初始化时把选中的磁盘**序列号**写进 `config.json`
2. 注册几个**计划任务**（最高权限、交互式登录），所以之后每次点击都不需要再确认 UAC
3. 点图标 → 触发任务 → 脚本按序列号找到那块盘 → `Set-Disk -IsOffline` → 更新图标和描述

卸载前还会：关闭指向该盘的文件资源管理器窗口 → 检查有没有程序从这块盘运行 →
采样 2 秒读写（只在**写入**超过 64 KB/s 时拦下）→ 刷写缓存 → 脱机 → 复查。

## 日志

两个 CSV，Excel 直接能开：

| 文件 | 内容 |
|---|---|
| `logs\actions.csv` | 结果汇总，每块盘每次操作一行 |
| `logs\steps.csv` | 过程日志，每个阶段一行（定位 / 联机 / 等盘符 / 脱机 / 复查…） |
| `logs\wakeups.csv` | 脱机期间盘被唤醒的记录（详见下） |

日志不进版本库，只在本机。

**关于"脱机期间有没有被唤醒"**：每次操作时工具会读一次 SMART 的启停次数和磁头加载次数，
和上次记录对比。如果盘在脱机期间被唤醒过，下次挂载时进度窗会停下来提示，
需要点「知道了」才关闭；同一事件也会记进 `wakeups.csv`。

注意这只是"疑似"——盘自己按电源策略停转、再被唤醒，计数同样会增加。

## 常见问题

**Q：为什么初始化要管理员权限？**
A：`Set-Disk -IsOffline` 本身就是管理员操作——把一块磁盘从系统里摘掉会影响整台机器，
Windows 只允许提权执行。但**只有初始化这一次需要**，之后走计划任务，不再弹 UAC。

**Q：会不会伤硬盘？**
A：正常开关盘不会。2.5 寸盘的设计指标通常是「启停 5 万次上下」，按每天开关 5 次算，
十年才 1.8 万次。真正需要注意的是**盘龄和温度**。

**Q：卸载时正在下东西怎么办？**
A：会被拦下来。脚本采样 2 秒读写，写入超过 64 KB/s 就不执行，并提示稍后再试。
（只认写入；纯读取不会拦，因为系统索引、缩略图会产生大量无害的读。）

**Q：能管理 U 盘 / 移动硬盘吗？**
A：能，初始化时勾上就行。移动硬盘还会顺带打开 USB 省电挂起，让它真正停转。

**Q：盘符变了怎么办？**
A：不用管。认盘靠序列号，图标上的字母角标会自动更新。

**Q：重启后盘会自己回来吗？**
A：不会。脱机状态是持久的，重启后依然是脱机——这也是它的价值所在。
拔插移动硬盘也不会自动联机（刻意如此，物理拔插不能绕过你的设置）。

**Q：怎么改管理哪些盘？**
A：再双击一次 `初始化.exe`，选「重新选盘」。

**Q：怎么卸载干净？**
A：删掉桌面上的快捷方式，再删掉这个文件夹即可。
计划任务可以在「任务计划程序」里删 `Disk-Mount` / `Disk-Unmount` / `Disk-Toggle*`，
或者先双击总开关把盘全部设回联机再删目录。

- Windows 10 / 11（中文或英文）
- 自带 .NET Framework 4.x 与 PowerShell 5.1，**无需安装任何东西**
- 整个文件夹可以整体拷到别的电脑直接用
